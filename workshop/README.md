# Workshop materials: find it, fix it, check it

A 90-minute workshop for designers, developers and writers, built on three standalone repos:

| Topic | Repo |
|---|---|
| Lighthouse | https://github.com/ucla-ux/lighthouse-audit |
| Alt text with AI | https://github.com/ucla-ux/wp-alt-text-workflow |
| Siteimprove and Alfa | https://github.com/ucla-ux/siteimprove |

Attendees need only Chrome and a Claude account. The terminal work is demo-only; hands-on is a spring session.

## Files

| File | Use |
|---|---|
| `ux-workshop-2026-ucla.deckset.md` | The slides, in UCLA blue, gold and Helvetica, with speaker notes and timings |
| `ux-workshop-2026-run-sheet.md` | Minute-by-minute schedule, audience poll tally, before-the-day checklist, fallbacks |
| `ux-workshop-2026-handout.md` | One page to print or share |
| `pre-work-spring.md` | Spring git training (Tower, Software Carpentry) and hands-on pre-work |

## Open the slides in Deckset (macOS)

1. Open **Deckset**, then **File → Open…** and choose `ux-workshop-2026-ucla.deckset.md`.
2. Present with **⌘⌥P**. Speaker notes are the lines starting with `^`.
3. **File → Export…** for a PDF copy.

Colors and fonts are set per slide with commands at the top of each slide. Helvetica is on every Mac but not on Windows, so share the PDF.
