# Accessibility with AI

Materials for the UCLA UX workshop **Find it, fix it, check it** (90 minutes, for
designers, developers and writers).

> Automated tools tell you **where to look**. They are much worse at telling
> you whether what you found is a problem, and they cannot tell you whether
> your fix helped anyone.

The workshop is built on three standalone repos, one per topic:

| Topic | Repo |
|---|---|
| Lighthouse | `github.com/ucla-ux/lighthouse-audit` |
| Alt text with AI | `github.com/ucla-ux/wp-alt-text-workflow` |
| Siteimprove and Alfa | `github.com/ucla-ux/siteimprove` |

This repo holds only the presentation materials, in [`workshop/`](./workshop/README.md):

```text
accessibility-with-ai/
├── README.md                              this file
└── workshop/
    ├── README.md                          how to open the slides in Deckset and export a PDF
    ├── ux-workshop-2026-ucla.deckset.md   the slides, with speaker notes (lines starting ^) and timings
    ├── ux-workshop-2026-run-sheet.md      minute-by-minute schedule, poll tally, before-the-day checklist, fallbacks
    ├── ux-workshop-2026-handout.md        one page to print or share: takeaways, repo links, quick steps
    └── pre-work-spring.md                 spring git training (Tower, Software Carpentry) and hands-on pre-work
```
